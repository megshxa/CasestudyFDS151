# Case Study 1: Transaction Analysis and Clustering of an Online Retail Store

**Name:** Megha Annavarapu | **Roll No:** 160124733151 | **Section:** CSE 3 | **Subject:** Fundamentals of Data Science

Market-basket analysis of 7,501 retail transactions: cleaning, descriptive statistics, PCA, and a comparison of
K-means, hierarchical, DBSCAN and spectral clustering using the silhouette coefficient and Davies-Bouldin index.

## Files
- `Case_Study_1_Retail_Clustering.ipynb` - full analysis with code, outputs and interpretations
- `case_study_1_retail_clustering.py` - the same code as a plain Python script
- `Case_Study_1_Report.pdf` - written report
- `Online retail_new.csv` - dataset
- `figures/` - saved plots

## Run
```
pip install -r requirements.txt
jupyter notebook Case_Study_1_Retail_Clustering.ipynb
```
Random seed 42 is used throughout.
